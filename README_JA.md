# EmDash To Discord

EmDash の記事を最初に公開したとき、Discord のチャンネルにカードを 1 回だけ投稿するプラグインです。カードには、タイトル、リンク、抜粋、アイキャッチ画像が入ります。

[English](README.md)

## 特徴

- **Webhook の URL だけで動きます。** ボットを作ったり、ログインしたりする必要はありません。
- **アイキャッチ画像がカードに出ます。** 標準の `featured_image` を使います。画像は Discord がサイトから取りに行くので、画像のデータは送りません。
- **接続先は Discord だけです。** 通信できるのは `discord.com` に限られます。Webhook の URL がほかへ送られることはありません。
- **二重に投稿しません。** 送信の前に記録を残すので、途中で止まっても自動では送り直しません。翻訳版は 1 つの投稿にまとめます。
- **だれにも通知しません。** タイトルや文面に `@everyone` などがあっても、メンションの通知は送りません。

## 動作の決まり

- プラグインを入れる前に公開した記事は、更新しても投稿しません。
- 自動では送り直しません。管理画面の「Discord Share」に記事ごとの状態が出ます。失敗や未送信の記事には「送る」のボタンがあります。Discord の送信制限（429）にかかったときは、メモに出る秒数だけ待ってから送ってください。
- 記事を更新したり消したりしても、Discord の投稿はそのままです。
- 画像は、公開した時点でのアイキャッチ画像を使います。公開のあとで付けた画像は、カードに出ません。
- Discord がサイトの画像を読めないときは、画像なしのカードになります。

## インストール

入れ方は 2 通りあります。

| 入れる元 | 動く場所 | Cloudflare のプラン | 入れ方と更新 |
| --- | --- | --- | --- |
| EmDash のプラグイン レジストリ | サンドボックス | **Workers Paid**（サンドボックスに必要） | 管理画面から |
| GitHub | サイトと同じ場所 | **Workers Free で動きます** | `npm install` のあと**デプロイ** |

### レジストリから

管理画面の **Registry** で **EmDash To Discord** を探して入れます。

サンドボックスには、処理ごとの通信回数に制限があります。EmDash 1.5 より前は 10 回、1.5 からは 30 回です。このプラグインの通信は、公開 1 回で最大 7 回、管理画面からの再送で最大 8 回なので、どちらの制限でも動きます。

### GitHub から

```sh
npm install github:RieTamura/EmDash-To-Discord
```

`astro.config.mjs` に足します。

```js
import discordShare from "discord-share";

emdash({
	// ...
	plugins: [discordShare],
});
```

デプロイします。更新するときも、同じ `npm install` のあとにデプロイします。管理画面からは更新できません。

## 設定

### 1. 暗号化の鍵を用意する

Webhook の URL の暗号化に、サイトの `EMDASH_ENCRYPTION_KEY` を使います。まだなければ作って、Worker に保存します。

```sh
npx emdash secrets generate
npx wrangler secret put EMDASH_ENCRYPTION_KEY
```

**鍵は別の場所にも保管してください。** 鍵はデータベースのバックアップに含まれません。なくすと、保存した URL を読めなくなります。

### 2. Webhook を作る

Discord で、投稿したいチャンネルの **チャンネルの編集 → 連携サービス → ウェブフック → 新しいウェブフック** を開き、**ウェブフック URL をコピー** します。投稿に出る名前とアイコンも、ここで決められます。

**この URL を知っている人は、だれでもそのチャンネルに投稿できます。** 人に見せたり、公開の場所に書いたりしないでください。漏れたときは、Discord でその Webhook を削除して作り直し、プラグインの設定を新しい URL に入れ替えます。

投稿を止めたいときは、「投稿するコレクション」を空にするか、プラグインを無効にします。Webhook URL の欄を空で保存しても、前の URL が残ります。

### 3. プラグインを設定する

| 設定 | 内容 |
| --- | --- |
| Webhook URL | 手順 2 でコピーしたもの |
| 投稿するコレクション | カンマで区切ります。既定は `posts` です。空にすると投稿しません |
| カードの上の文 | 既定は空（カードだけ）。2000 文字まで |
| カードのタイトル | 既定は `{title}`。256 文字まで。空なら `{title}` になります |
| カードの説明 | 既定は `{excerpt}`。4096 文字まで。空なら説明を出しません |
| アイキャッチ画像を出す | 既定はオン |
| `{date}` のタイムゾーン | `Asia/Tokyo` など。既定は `UTC` |

文面では、次の変数が使えます。上限を超えた文は、末尾を切って「…」を付けます。知らない変数は、そのまま残します。

| 変数 | 中身 |
| --- | --- |
| `{title}` | 記事のタイトル |
| `{url}` | 記事の公開 URL |
| `{excerpt}` | 抜粋 |
| `{date}` | 公開日（`YYYY-MM-DD`） |
| `{collection}` | コレクションの名前 |

**投稿するコレクションに、ほかのサービスから取り込むコレクション（RSS や Bluesky など）を入れないでください。** 取り込んだ記事を投稿してしまいます。

## 開発

```sh
npm install
npm test
npm run build
```

テストは Worker Loader の上で動きます。ただし、本番の CPU や通信回数の制限までは再現しません。
